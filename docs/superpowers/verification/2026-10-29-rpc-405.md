# 0.7.7 远程 RPC 405 修复验证

日期：2026-10-29。任务：89（独立复核 + 发布）。88 = 改动方（Host/Client namespace），89 只做验证与打包。

## 一、根因（读官方源码，不是假说）

- 官方路由（`@deepseek-ai/dsh-host-webserver@0.2.1-rc.2` `lib/index.js:495-504`）：`match()` 先查 exact 表，
  再在 prefix 表里 **最长 prefix 优先**，命中条件 `pathname === prefix || pathname.startsWith(prefix + '/')`；
  `:378-394` 命中即把请求交给该 route 的 handler。
- 官方 `/api` 载体（安装包 `@deepseek-ai/dsh-client-connection` 的 Host 半侧 `lib/index.js`）以
  `{ kind: 'prefix', path: '/api' }` 挂载（`:829-843`），用 `endpointFromPath(channel, pathname) = pathname.slice(len+1)`
  解析 endpoint（`:711-716`），`rpcFetchHandler` 只接 **POST + application/json + envelope
  `{type:'client-request',rpcId,method,payload}`**，并要求 `message.method === endpoint`（`:660-700`）。
- Client 真实 wire（同包 `lib/client.browser.js:1212-1226`）：`POST` 到 `` `${channel}/${endpoint}`.slice(1) ``，
  即 **endpoint 直接成为 URL 后缀**。所以 endpoint 名 `dsh-team-member-model/<op>` 的 URL
  `/api/dsh-team-member-model/<op>` 必然先命中插件自己的 HTTP prefix `/api/dsh-team-member-model`（更长），
  POST 落到只认 GET/PUT 的 `executeApi` → **405**，官方 carrier 永远轮不到。0.7.6 现场报的正是这个 405。

## 二、独立 A/B（同一 fixture，真 socket）

fixture：真 `node:http` server + 逐字复刻的官方解析器（`match()` 与 `endpointFromPath` 各 10 行，注明来源行号）
+ `/api` carrier 契约 + 插件自己 `apply()` 出来的真 route/interceptor，认证用 owner Peer fixture（不读真实 cookie）。

- **0.7.6 归档**（`artifacts/remote-access-2026-10-28/...0.7.6.tgz` 解包到 /tmp）：
  `POST /api/dsh-team-member-model/teams` → 选中 `prefix:/api/dsh-team-member-model` → **405**
  `{"ok":false,"error":"method not allowed: POST"}`；`POST /api/team-member-model/teams` → 选中 `prefix:/api` → 404
  （0.7.6 的 interceptor 不认新 namespace）。
- **修复后工作区**：同一条旧路径 POST → 仍 **405**（不 fallback、不绕 guard）；`POST /api/team-member-model/teams`
  → 选中 `prefix:/api` → **200** `{"type":"server-response",...,"result":{"ok":true,"value":{"status":200,...}}}`；
  `saveTeam` 缺字段 → outer 200 + 业务 400（严格 schema 未放宽）；`GET /api/dsh-team-member-model/state` → 200；
  `PUT /api/dsh-team-member-model/policy` 无标记头 → 403。
- namespace 断言：旧 interceptor `matches('team-member-model/teams') === false`；新 interceptor 对新 namespace
  `true`、对旧 namespace `false`（不存在双写/兼容旁路）。
